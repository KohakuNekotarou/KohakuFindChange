## 1. どの行をクリックすると何が起きるか

- **JMP-01** すべての行が、クリックで**どこかへ行く** ――
  **ヒットの行**＝その一致へジャンプ／**文書の行**＝その文書の窓を前に出す（スクロールも印も無し）／
  **ストーリーの行**＝その行がある文書の窓を前に出す（文書の行と同じ）／
  **ブックの行**＝そのブックをアクティブにし、ブックパネルでそのブックのタブを前に出す。
  （run の行は 2026-10-06 に外した＝Show Changes ごと。）
  - 訂正:

- **JMP-02** クリックの動きは**ボタンを離したとき**に起きる（押したままドラッグした・行の外で離した、は行き先の指定にならない）。
  Shift・Ctrl を押しながらのクリックは選択の操作なので、ジャンプしない。
  - 訂正:

- **JMP-03** （2026-10-06 に外した＝チェックボックスごと・F16）
  - 訂正:

- **JMP-04** ブックの行のクリックで、**検索した後に閉じられたブックは開き直さない**（`That book is no longer open.`）。
  行が表すのは「検索したブック」で、ファイルを開く頼みではないため。
  - 訂正:

- **JMP-05** ジャンプは**1つずつ**。章を開いている最中に来た次のクリックは、捨てる（開いている最中の状態から次のジャンプや選択を始めないため）。
  - 訂正:

## 2. ヒットの行へのジャンプ

- **JMP-06** ★ジャンプは**選択しない** ―― 一致の位置まで画面を動かして**印**を出すだけ（VS Code の「場所を示す」の形）。
  1回のクリックは文書を何も変えないので、気軽に使える。選択するのはダブルクリック（§4）。
  - 訂正:

- **JMP-07** ジャンプの順 ――
  ①その章（文書）に届くようにする（閉じていたら、ファイルから窓なしで開き直す）
  ②一致がまだそこにあるか確かめる（置換した行なら、書いた文字がそこにあるか。無ければ探し直す＝§3）
  ③文書の窓を前に出す（無ければ最初の窓を開く・最小化されていたら戻す）
  ④一致のあるスプレッドを表示し、**一致の最初の行を窓の真ん中**にスクロールする
  ⑤印を出す。
  （置換した行の位置を変更履歴の記録から取り直す段は 2026-10-06 に外した＝KFC が記録を付けなくなったので。代わりに書いた文字で探し直す＝JMP-14。）
  - 訂正:

- **JMP-08** 窓を開く・前に出すときは、**今見ている窓の拡大率を引き継ぐ**（新しく開く窓は、その拡大率で開く）。
  - 訂正:

- **JMP-09** ジャンプで窓が付いた章は、**その瞬間から利用者のもの**になり、KFC はもう閉じない（SCOPE-18）。
  ★「ジャンプで開いた文書は、何も置換していなくても閉じないでほしい」（2026-08-03 の決定）。
  - 訂正:

- **JMP-10** ジャンプは文書を「変更あり」にしない（組版のやり直し・窓を開く・スプレッドを変えるで立つ印を、入る前の状態に戻す）。
  - 訂正:

- **JMP-11** **あふれた一致**は、置かれた文字が無いので、あふれの「＋」の位置へスクロールするだけで**印は出さない**（その画素は「＋」のもの）。
  （Show Changes の一覧の非表示の条件の中の行の決まり（2026-10-04）は、Show Changes ごと 2026-10-06 に外した。）
  - 訂正:

- **JMP-12** ジャンプできないときは、メッセージ欄に理由を出す ――
  章に届かない＝`Cannot open that chapter - moved, deleted, or in use?`／窓を前に出せない＝`Cannot bring that chapter's window to the front.`／
  行に場所が無い（守り＝検索が作る行にはいつも場所があり、KFC が場所を消すことも無い）＝`This row has no place in its story to go to. Search again.`（2026-10-08 に `deleted` の行の文から改めた）
  どの場合も、前のジャンプの印は消す（動かなかった画面の上に古い印を残さない）。
  - 訂正:

## 3. 一致がもうそこに無いとき

- **JMP-13** 「同じ一致か」は、**一致の全体**（の指紋）と**前後の文字**で確かめる（同じ語が近くにもう1つあっても取り違えない）。
  - 訂正:

- **JMP-14** ★そこに無ければ、**同じストーリーを同じ検索条件で歩き直し**、「同じ文字で、前後も同じ」一致が**ちょうど1つ**で、
  ほかの行が使っていなければ、行をそこへ**黙って移す**（2026-09-27 の決定＝取り消しなどで位置がずれた行を救う）。
  検索の条件が変わっていたら探し直さない。
  ★**置換した行**は、検索の条件ではなく**置換で書いた文字**を、同じストーリーの中で探し直す ―― 同じ文字・同じ前後の行（書いたときに読み直したもの）が
  ちょうど1つで、ほかの行が使っていなければ移す（2026-10-06・F4。それまでは変更履歴の記録から取り直していた）。
  消すだけの置換（書いた文字が空）の行は探し直さない。
  - 訂正:

- **JMP-15** 探し直しても見つからなければ ―― 画面は**それでも元の位置へ動かし**（一致があった場所を見せる）、印はそこに今ある文字の上に出す。
  行には `missing` が付き、メッセージ欄は `Not found - the text is no longer where the search left it. Search again.`
  置換した行なら行はそのままで、`The replacement is no longer here - undone, or edited since.` と言う。
  ストーリーが短くなって元の位置が無ければ、ストーリーの最後の文字へ行く（2026-10-03）。
  - 訂正:

## 4. ダブルクリック ―― 選択する

- **JMP-16** ヒットの行のダブルクリックは、1回目のクリックでジャンプし、2回目で**一致を選択する**（2026-08-09 から）。
  ⚠**ツールが文字ツールに切り替わる**（選択の後すぐ打ち込めるように。手のひら・ズームなどのツールのままだと打てないため）。
  ⚠コードの注は「How to Use に書いてある」と言うが、How to Use の本文は「一致した文字列を選択します」だけで、ツールが変わることは書いていない。
  - 訂正:

- **JMP-17** 選択できたら印は消える（反転と選択が重なると文字が読めないため）。キーボードも文書に戻る（すぐ打ち込めるように）。
  ★1回目の印はすぐに出し、2回目で消す（KCM の Story のジャンプと同じ拍子＝2026-09-25 の決定。それまでは印をダブルクリックの間だけ遅らせていた）。
  - 訂正:

- **JMP-18** ★選択しないもの（2026-08-09 の決定）―― ロックされた一致（`That match is locked - it cannot be selected.`）／
  非表示のレイヤーの一致（`That match is on a hidden layer - it cannot be selected.`）／幅の無い一致＝`^` `$` 先読みなど（`That match has no width (^, $ or a lookaround) - there is nothing to select.`）／
  あふれた一致（`An overset match has no text on the page to select.`）／一致がもうそこに無い行（ジャンプが理由を言っているので黙る）／
  その文書の窓が前に出ていない（ジャンプが失敗したか、まだ開いている最中＝黙る）。
  選択しないときは、ジャンプの印をそのまま残す（「どこか」は答えられるので）。
  - 訂正:

- **JMP-19** 文書の行・ブックの行のダブルクリックは、木を開く／閉じるだけ（本体の木の動き）。
  - 訂正:

## 5. 印

- **JMP-20** 印は**一致の文字の上に白い反転**で出し、**約1秒**で自分で消える。一致が何行にまたがっても全部の行に出る。
  幅の無い一致は細い縦線。縦組み・回転したフレーム・連結したフレーム・表のセルの中でも文字の上に出る（2026-09-26 から）。
  - 訂正:

- **JMP-21** ★印は**画面だけ** ―― どの画面モード（標準・プレビュー・オーバープリントプレビュー）でも出るが、
  **印刷・PDF などの書き出し・ページの絵**（サムネイル、KIDMCP や KCM が撮るページ画像）には出ない
  （2026-07-31・09-26 の決定＝場所を示す道具で、作品の一部ではない。ページの絵に写っていたのを 2026-10-03 に直した）。
  - 訂正:

- **JMP-22** 新しいジャンプは、前の印を置き換える（印は1つだけ）。文書の行・ブックの行のクリックでは、前の印を消さない（1秒で消えるので）。
  - 訂正:

## 6. 矢印キー

- **JMP-23** 行をクリックした後は、**上下の矢印キーで木を歩ける**。止まった行の動き（ジャンプなど）がクリックと同じに起きる。
  - 訂正:

- **JMP-24** 矢印キーが**閉じた行に止まると、その行を開く** ―― ブックを検索すると章が閉じて出るが（ROW-02）、
  下の矢印を押し続ければ、ブック全体のヒットを順に巡れる。Home・End・PageUp・PageDown・左右の矢印は本体の木の動きのまま。
  - 訂正:

- **JMP-25** 1回クリックした後もキーボードは**木に残る**（矢印で続けて歩けるように）。ダブルクリックで選択したときだけ、文書に戻る（JMP-17）。
  - 訂正:

## 7. Hide Previous Chapter

- **JMP-26** ★**Hide Previous Chapter が ON** のとき、ジャンプ（または文書の行のクリック）で着いた文書**以外**の、
  **検索したブックの章のうち、窓のある・保存の要らない文書を閉じる**（誰が開いたものでも。ブックに入っていない文書は閉じない＝JMP-28）。
  編集した文書・一度も保存していない文書は残す。**起動のたびに ON から始まる**（Save Panel Settings で保存すれば、その値で始まる）。
  - 訂正:

- **JMP-26b** ⚠PDF などを**後ろで書き出している最中**の文書は、Hide Previous Chapter でも**閉じない**（InDesign が、書き出しに使っている文書を閉じる頼みを受け付けず、捨てる。書き出しが終わった後に閉じることもない）。
  開いたまま残るだけで、失うものは無い（打った文字も残る）。前もって聞いて飛ばす口はあるが、見える結果が同じなので使っていない（2026-10-04 実測）。
  - 訂正:

- **JMP-27** 働くのは**ブックを検索した結果のときだけ**（文書の結果では、ほかの文書を閉じる理由が無い）。
  メニューも、Book Scope が ON のときか、ブックの結果が出ているときだけ押せる（それ以外は灰色・チェックの印は見えたまま）。
  （文書の結果でほかの文書まで閉じていて、しかもメニューが灰色で止められなかったのを 2026-08-03・08-09 に直した。）
  - 訂正:

- **JMP-28** ★**ブックの外の文書は閉じない**（2026-10-08 の作者の決定＝09-26 の R-2「ブックの外の保存済みの文書も閉じる・いまのまま」を覆した）。章かどうかは、検索したブックの章のファイルと**ファイルとして**比べる（SCOPE-13・古い版から変換した章も章として閉じる）。参考に開いた別の文書・章を別名で保存した写し・無題の文書は残る。回帰＝`hb-keep-outside-doc`／`hb-user-chapter-still-closes`。
  - 訂正:

## ⬜ この章で未確認

この章を書くにあたって**確かめていない**もの。「書いていない＝そういう決まりが無い」ではない。

- JMP-08：拡大率を引き継ぐのは「前に出ていた窓」から。複数の窓を並べているときにどれが「前」になるかは測っていない。
- JMP-14：探し直しで候補が2つ以上あったときは移さない（コードの約束）。そのときの行が `missing` になるかは、この章では確かめていない。
