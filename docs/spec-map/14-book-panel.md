# 14. ブックパネルの位置を覚える（Remember Book Panel Placement）

> コード地図での位置: ブロック **16**（`ui/KBSBookPanelPlacement.*`・`ui/KBSBookPanelLookup.*`）。
> トグルを押したときの保存とメッセージ欄の文は第12章（SET-20・SET-21）。
> 訂正の書き方は [00-index.md](00-index.md)。

---

## 1. 何をするか

- **BPP-01** InDesign の**ブックパネル**は、ブックごとに作り直されるので、最後のブックを閉じると、次のブックは**既定の場所と大きさ**で開く（どこに置いていても）。
  21.0 での実測＝(900,300) に動かして閉じ、開き直すと (532,252) 304×275 に戻った。
  ON にすると、KFC が**閉じる直前の場所を覚えて、次に開いたときに戻す**（2026-09-25 の作者の依頼）。
  - 訂正:

- **BPP-02** **最初は OFF**。押した瞬間に、この項目だけを設定のファイルに書く（SET-20）。
  - 訂正:

- **BPP-03** ★場所を測るのは、**ブックが閉じる直前**（ブックパネルの「ブックを閉じる」・スクリプト・InDesign の終了、どれでも＝終了はブックを先に閉じるので）。
  InDesign は、ブックパネルが消えることを知らせてこないので、**閉じる命令が走る直前**がただ1つの機会（2026-09-25 実測＝最初の版は閉じる知らせを待っていて、何も覚えなかった。作者の試し「閉じて開き直したら戻らない」）。
  - 訂正:

- **BPP-04** 測った場所は、すぐに設定のファイルへ書く（ブックパネルの項目だけ）。うまくいったときは黙っている。
  書けなかったときだけ、メッセージ欄に `Book panel placement could not be saved (…).`
  - 訂正:

- **BPP-05** `Save Panel Settings` を押したときも書く ―― ブックパネルが開いていれば**その場の位置**、無ければ最後に覚えた位置（SET-16）。
  InDesign の終了の後始末でも、ブックパネルが残っていれば測る（ふつうはもうブックが閉じているので、念のため）。
  - 訂正:

- **BPP-06** 戻すのは、**ブックパネルが1つも無かったところに現れたとき**だけ。現れてから**約0.1秒後**に戻す（InDesign がパネルを並べ終えるのを待つ）。
  ほかのブックが開いているところに開いたブックは、そのパレットにタブで入るので、**動かさない**（動かすと、もう開いているブックパネルまで動く）。
  - 訂正:

- **BPP-07** ブックがいくつも開いているときは、ふつうブックパネルは1つのパレットのタブなので、**最初に見つかったブックパネル**を測る。
  ブックパネルを別々のパレットに引き離していても、見分けない。
  - 訂正:

## 2. 浮いているとき

- **BPP-08** 浮いたブックパネルで覚えるもの ―― パレットの左上の位置・ブックパネルの大きさ・アイコンに畳んでいるか（とアイコンの帯の幅）。
  - 訂正:

- **BPP-09** ★浮いたパレットを**ほかのパネルと共有**していたときは、その隣も覚える（同じタブの組のパネルとタブの位置・すぐ下の組・すぐ上の組）。
  戻すときは、そのパレットが**開いていれば、そこへ戻す**。閉じていれば、自分の場所と大きさで戻す（見えないパレットには入れない）。
  （2026-09-25 の作者の報告で足した＝浮いた KFC のパネルにタブで入れたブックパネルが、別のパレットとして KFC の真上に重なって戻ってきた。）
  - 訂正:

- **BPP-10** 自分の場所で戻すときの順番 ―― **場所→大きさ→アイコンの畳み**。
  大きさは、ブックパネル自身の丸めを通す（380×420 を頼むと 380×400 になる）。新しい場所で**下の端が画面の外**に出るなら、高さを縮める。
  - 訂正:

- **BPP-11** 覚えた場所の**上の帯が、どの画面にも 40px 以上かからない**とき（そのモニターがもう無いなど）は、戻さない（InDesign の既定の場所のまま）。
  - 訂正:

## 3. ドックに入っていたとき

- **BPP-12** ★ドックの中の場所は、座標ではなく**隣にいたパネル**で覚える（ドックは「列の並び→組の並び→タブの並び」でできていて、本体のパネルの番号は起動しても変わらないので＝2026-09-25 の作者の依頼「ドックの中の、その並びに」）。
  隣のほかに、**どのドック（左右）の何番目の列か**（2026-09-27 から）と、列がアイコンに畳まれているかも覚える。
  - 訂正:

- **BPP-13** 戻すときは、近い隣から順に探して、最初に見つかった所へ入れる ――

  ```
  1. 同じタブの組にいたパネル → その組の、前と同じタブの位置へ
  2. すぐ下の組のパネル       → その組のすぐ上へ
  3. すぐ上の組のパネル       → その組のすぐ下へ
  4. 後ろの列のパネル         → その列の手前に新しい列を作って
  5. 前の列のパネル           → その列の後ろに新しい列を作って
  6. 隣が1つも無い            → 同じドックの同じ番目に新しい列を作って
  ```

  新しい列は、前と同じアイコンの畳みと幅にする。
  - 訂正:

- **BPP-14** ★文書と、ドックに入れた**ツールパネルの間**にあった列は、その間に戻す（2026-09-27 に直した＝InDesign の新しい列の作り方ではツールパネルの外側に置かれ、次に閉じるとその場所を覚えてしまっていた。左右どちらのドックでも）。
  - 訂正:

- **BPP-15** 隣が誰もいなくて、ドックも分からない（2026-09-27 より前に書いたファイル）ときは、InDesign が置いた場所のまま。
  - 訂正:

- **BPP-16** 新しく開いたブックパネルを、**InDesign 自身がもうドックに入れていたら、触らない**（InDesign 自身の記憶が働いているので）。
  - 訂正:

- **BPP-17** ★InDesign が**ドックから放り出す**ことがある（InDesign を起動していないときに `.indb` をダブルクリックして開くと、戻した数秒後に、隠れた浮いたパレットへ出される＝4回中3回・2026-09-27 実測）。
  そのときは、知らせが止んでから（約1.5秒）**もう一度戻す**。1回開くごとに**3回まで**（InDesign と張り合い続けないため）。
  - 訂正:

- **BPP-18** ★**ホーム画面**がドックを覆う場合 ―― InDesign の起動と一緒にブックを開くと、ホーム画面が出たままになり、戻したドックが見えない。
  そのときは、KFC が**ブックを閉じて開き直す**（利用者がするのと同じ＝InDesign の中からブックを開くとホーム画面が消える）。2026-09-27 の作者の決定「InDesign から開いたときのように、ドックが見えるのが一番」。
  条件はすべて ―― 覚えた場所がドック・ホーム画面が出ている・文書が1つも開いていない・どのブックも変更されていない・その起動でまだ1回もしていない。
  - 訂正:

- **BPP-19** ★BPP-18 は**起動から60秒以内**で、まだ文書を1つも開いていないときだけ（2026-10-03 に直した＝起動の後、最後の文書を閉じてホーム画面が出たときにもブックを開き直し、ブックパネルが既定の場所に戻っていた）。
  - 訂正:

## 4. そのほか

- **BPP-20** ★閉じる命令を見張る仕掛け（InDesign のすべての命令が通る）は、**ON の間だけ**置く（2026-09-25 の監査で直した＝それまでは OFF の人にも置いていた）。
  - 訂正:

- **BPP-21** 変更されたブックを閉じようとして、保存の確認で**キャンセル**したときは、場所は測られるが、ブックパネルは残る。次の知らせで、今いる場所に戻すだけ（見た目は動かない＝2026-10-03 実測）。
  - 訂正:

- **BPP-22** ⚠戻したブックパネルのアイコンが、**KFC のアイコンで描かれた**ことが2回ある（2026-09-25・作者）。KFC はパレットのアイコンを書いていないので、InDesign がドックへ移したときの描き方と見ている（確かめていない）。見た目だけなので、作者の了解でそのまま。
  - 訂正:
