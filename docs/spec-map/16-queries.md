## 4. 右の並び（Run Order）とボタン

- **QRY-11** 右は実行する順の並び。行は `<番号>  <種類>  <名前>`。**同じクエリを何度入れてもよい**。
  並びにあるクエリのファイルが無くなっていたら、行の末尾に ` (not found)`。
  - 訂正:

- **QRY-12** 間のボタンは5つ ――

  ```
  Add >
  < Remove
  Move Up
  Move Down

  Clear
  ```

  `Add >`＝左で選んだクエリを右の最後に足す（足した行が選ばれる）／`< Remove`＝右で選んだ行を外す（選択は同じ位置の次の行へ・最後の行なら前の行へ）／
  `Move Up`・`Move Down`＝右で選んだ行を1つ動かす（選択が付いていく）／**`Clear`**＝右の並びを全部外す（2026-10-07 の作者の追加「Runするほうのを初期化するボタン」）。
  どちらの一覧も、選べるのは1行だけ。
  - 訂正:

- **QRY-13** 押せないボタンは灰色 ―― `Add >`＝左で何も選んでいない／`< Remove`＝右で何も選んでいない／`Move Up`＝右の先頭の行か未選択／
  `Move Down`＝右の最後の行か未選択／`Clear`＝右が空。
  - 訂正:

## 6. Runs on: の行

- **QRY-17** ダイアログの下の行は、**Run がどこに当たるか**か、**走れない理由**を言う。Run が実際に使う判断と同じもの（第3章）から作るので、食い違わない ――

  ```
  Runs on: the book "<ブック>" (<数> document(s)).
  Runs on: <数> selected document(s) of the book "<ブック>".
  Runs on: All Documents (Search: in Edit > Find/Change).
  Runs on: Document "<文書>" (Search: in Edit > Find/Change).
  Runs on: Story in "<文書>" (Search: in Edit > Find/Change).
  Cannot run: <理由>
  ```

  2つ目は Find/Change Selected Documents (Book) で一部の文書を選んでいるとき（SCOPE-26〜）。`To End of Story`・`Selection` も `Story` と同じ形。
  ブックの名前は拡張子つき（`Manual.indb`）。
  - 訂正:

- **QRY-18** 開いている間に範囲が変わっても行は追いつく ―― 開いたとき・開き直したとき・Run の後、それに KFC のパネルがタブ名の範囲を描き直すとき
  （選択・「検索と置換」の設定・Book Scope・トグルの変化）に読み直す。文字が変わったときだけ書き直す。
  - 訂正:

## 7. Run

- **QRY-19** ★**Run はいつでも押せる**（灰色にしない）・**Enter でも走る**・**Run でダイアログは閉じない**（続けて使える）。
  パネルに検索の結果が出ていても走る（走り始めに一覧を消す）。確認のダイアログは出さない
  （2026-10-07 の作者の変更「Runはいつでおせる、パネルに検索結果などがひょうじされていても、おすと、そちらのRunが走る」）。
  - 訂正:

- **QRY-20** Run は右の並びの順に、各クエリを**本体の Change All**（一覧なし・上限なし）で、範囲の各文書に書く（10-06 の設計 F7）。
  範囲は QRY-17 の行のとおり。ブックなら章を先に全部開いて抱え、書いた章には窓を付け、書かなかった章は閉じて返す（第3章と同じ）。
  終わってもパネルに一覧は出さない。
  - 訂正:

- **QRY-21** ★実行全体で **Ctrl+Z 1回**（取り消しの段は1つ）。終わると「検索と置換」の設定を空にする（同梱スクリプト FindChangeByList.jsx と同じ考え方）。
  - 訂正:

- **QRY-22** 結果はパネルのメッセージ欄に ――
  `Ran <N> queries: <合計> replaced (1: <数>, 2: <数>, 3: -).`（`-`＝飛ばしたクエリ・1本なら `query:`）。
  選んだ文書のときは `… replaced (…) in <S> selected document(s) of <T>.`。
  飛ばしたクエリは ` Skipped <n> queries: file not found (<名前>, …).`／` Skipped <n> queries: nothing to find (<名前>, …).`
  （Object・Color のクエリと、検索する文字も形式も無いクエリは後者）。開けなかった章・窓なしで残った章の注は第3章と同じ。
  - 訂正:

- **QRY-23** 走れないときは、何も書かずにメッセージ欄が言う ――
  `No queries in the run order.`（右が空）／`None of the queries' files was found - nothing was run.`／範囲の断り（`Cannot run:` の行と同じ理由）／
  `That book has no chapters.`／`No document of the run could be opened - nothing was run.`／ほかの実行が走っている間はその旨。
  途中のキャンセルと失敗は全部を巻き戻す（`Cancelled - nothing was changed.`／`Stopped - nothing was changed: <理由>.`）。
  - 訂正:

- **QRY-24** KFC のパネルが閉じていても Run は走る。結果の文はパネルのメッセージ欄に残る（次にパネルを開いたときに読める＝ショートカットで押した Find や Change All in Book と同じ）。
  - 訂正:

- **QRY-25** ★**ダイアログの中にもメッセージの行**（「Runs on:」の下）。QRY-22・QRY-23 の文と、並びのファイルが読めない／書けないときの文を、**パネルのメッセージ欄と同じ文で**ここにも出す。ダイアログを開くたびに空から始まる。（2026-10-07 作者の判断＝3案から案1。ダイアログはモードレスで KFC のパネルを閉じたまま出しておけるので、パネルが閉じていると Run の結果がどこにも出なかった。モーダルにする案は取らない＝「Runs on:」の行が範囲の変化に追いつくので取り違えは起きず、出したまま次の文書へ移れる便利さを残す。）
  - 訂正:
