# 15. アプリケーションバーの検索欄（Link the Application Bar's Search Field to This Panel）

> コード地図での位置: ブロック **17**（`ui/KFCAppBarSearchEnter.*`）。
> トグルを押したときのメッセージ欄の文は第12章（SET-09）、保存は SET-16。
> 訂正の書き方は [00-index.md](00-index.md)。

---

## 1. 何をするか

- **BAR-01** ★ON の間、InDesign の**アプリケーションバーの検索欄**（Adobe Stock／Adobe Help の三角が付いた欄）と、**編集 > 検索と置換**を、1つのものとして動かす（2026-10-02 の作者の設計・名前は 10-03）――
  欄に**検索と置換のクエリーを映し**、欄で **Return を押すと、このパネルで検索する**（Adobe Stock／Help の検索の代わりに）。
  - 訂正:

- **BAR-02** **最初は OFF**。OFF の間は、欄に**一切触らない**。
  - 訂正:

- **BAR-03** ★トグルの場所は、このパネルのフライアウト（欄の三角のメニューは Windows のメニューではなく、項目を足せなかったため）。
  ★最初の設計（三角で選んだ方でタブを決める＝Stock→テキスト、Help→正規表現）は、同じ日（2026-10-03）にやめた。
  - 訂正:

---

## 2. 欄に映すもの

- **BAR-04** 欄には、検索と置換が**今いるタブのクエリー**を映し、変わるたびに追いかける（検索文字列に1文字打つごとにも）――

  ```
  テキスト   → 検索文字列
  正規表現   → 検索文字列
  字形       → 「文字 (GID 8123, Kozuka Mincho Pr6N R)」の形
  文字種変換 → 文字の種類（InDesign の UI の言葉で。例「半角カタカナ」）
  オブジェクト・カラー → 欄に触らない
  ```

  ON にした瞬間にも映す。中身が同じなら書かない（欄にいる人のキャレットを動かさないため）。
  - 訂正:

- **BAR-05** ★字形は、字形が表す**文字**（フォントが答えれば）、字形の番号、フォント（ファミリーとスタイル）を並べる。BMP の外の文字も1文字として出す（2026-10-03）。
  - 訂正:

- **BAR-06** ★文字種変換の名前は、**InDesign 自身の文字種変換タブと同じ言葉**（2026-10-03 の作者の決定＝最初の英語の名前は UI の言葉ではなかった）。
  - 訂正:

- **BAR-07** ★InDesign は、欄を作るとき（起動の約24秒後に作り直す）と、メニューを使ったときに、欄へ**自分の「Adobe Stock」を書き戻す**。
  そのときは、**すぐにクエリーを書き直す**（2026-10-03 の作者の決定「O-1 も直す」＝それまでは「Adobe Stock」のまま残り、Return でそれを検索していた）。
  - 訂正:

- **BAR-08** BAR-07 の書き直しをしないとき ――
  - 欄に**キーボードの入力が向いている**とき（それは人の編集なので）
  - KFC が書き直した**0.5秒以内**に InDesign がまた書いたとき（張り合いが続かないよう、検索と置換が次に変わるまで欄は InDesign に任せる）
  - 訂正:

## 3. 欄で Return を押したとき

- **BAR-09** 欄で、**修飾キーなしの Return** を押し、欄に文字があれば ―― InDesign の Adobe Stock／Help の検索を**止めて**（ブラウザーは開かない）、このパネルで検索する。
  - 訂正:

- **BAR-10** そのまま InDesign に任せるもの ――
  - 欄が**空**の Return
  - **Shift・Ctrl・Alt** を押しながらの Return
  - 日本語入力の**変換を確定する** Return（別のキーとして届くので、日本語入力の邪魔をしない）
  - 訂正:

- **BAR-11** キーを押したままの繰り返しは、止めるが、検索は**1回だけ**。
  - 訂正:

- **BAR-12** ★検索するのは、検索と置換のタブが**テキストか正規表現のときだけ**（2026-10-03・最初の実機確認での作者の決定）。
  ほかのタブでは、Return は止めるが**何も検索しない**。パネルが開いていれば、メッセージ欄に
  `Application Bar link: Return searches on the Text and GREP tabs only - nothing was searched.`（パネルは開かない）
  - 訂正:

- **BAR-13** テキスト・正規表現のときの順番 ――

  ```
  1. パネルが閉じていれば開く（キーボードの入力は欄に残したまま）
  2. 欄の文字が、そのタブの検索文字列と違えば、検索と置換に入れる
  3. フライアウトの Find in … と同じアクションで検索する
  ```

  ⇒ 範囲・灰色の確かめ・進捗バー・メッセージ欄は、フライアウトの検索とまったく同じ（第2章・第3章）。
  検索と置換に入れられなかったときは `The Application Bar's text could not be put into Find/Change - nothing was searched.` で止まる。
  - 訂正:

- **BAR-14** 欄の文字は、1,024文字までを読む（それより長いと切れる）。
  - 訂正:

## 4. 欄が見えないとき・OFF・終了

- **BAR-15** アプリケーションバーは、メニューを2段にしないと入らない幅のとき、**検索欄を隠す**（2026-10-02 実測）。
  そのとき ON にすると、メッセージ欄は `Application Bar link: on - works while the Application Bar's search field is shown.`（SET-09）。
  隠れた欄でも、仕掛けそのものは働く（2026-10-03 実測）。
  - 訂正:

- **BAR-16** OFF にすると、Return を見る仕掛けと、欄を書き直す仕掛けを外し、検索と置換を追いかけるのもやめる。まだ走っていない検索・書き直しは取りやめる。
  欄に映していた文字は、消さずにそのまま。
  - 訂正:

- **BAR-17** ★Return を見る仕掛けは、**ON の間だけ**置く（InDesign のメインのスレッドだけを見る。ほかのアプリケーションには掛からない）。
  - 訂正:

- **BAR-18** InDesign を終了するとき、仕掛けをすべて外してから終わる。
  - 訂正:

## ⬜ この章で未確認

この章を書くにあたって**確かめていない**もの。「書いていない＝そういう決まりが無い」ではない。

- BAR-08：**人が欄に打ち込んでいる最中**に書き直さないことは、コードの注から読んだもの（打ち込みは書き直しの知らせにならない）。この開発機では欄が隠れているので、人が打ち込む形では測っていない。
- BAR-16：OFF にした後、欄がいつ InDesign 自身の「Adobe Stock」に戻るか（次に InDesign が欄に書いたとき、の見込み）は測っていない。
- BAR-13：Find in … が灰色の状態（範囲に対象が無い・オブジェクトのタブ）で Return を押したときに、アクションがどう断るかは、この章のためには測っていない。
- BAR-05：字形のフォントの名前が UI の言語でどう出るか（日本語名か英語名か）は見ていない。
