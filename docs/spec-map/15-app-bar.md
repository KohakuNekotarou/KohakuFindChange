## 2. 欄に映すもの

- **BAR-04** 欄には、検索と置換が**今いるタブのクエリー**を映し、変わるたびに追いかける（検索文字列に1文字打つごとにも）――

  ```
  テキスト   → 検索文字列
  正規表現   → 検索文字列
  字形       → 「文字 (GID 8123, Kozuka Mincho Pr6N R)」の形
  文字種変換 → 文字の種類（InDesign の UI の言葉で。例「半角カタカナ」）
  オブジェクト・カラー → 欄に触らない
  ```

  ON にした瞬間にも映す。中身が同じなら書かない（欄にいる人のキャレットを動かさないため）。
  - 訂正: ★2026-11-07 作者の決定（「タブがどんなところにはいっていも、Textの検索になるように、Textの入力を表示する様にして欲しい」・その前に作者の判断待ちの答えとして「表示も Text だけ」）＝**欄に映すのは、どのタブでも検索と置換のテキストタブの検索文字列**（正規表現・字形・文字種変換・オブジェクト・カラー・KFC の Kohaku+ タブのときも同じ）。上の表はそれまでの形。テキストタブの検索文字列が変わるたびに追いかけるのは今までどおり。回帰 `bar-grep-shows-text`・`bar-object-return-text`・`bar-grep-open-dialog`・`qr-appbar-enter`・`kt-appbar-enter`・`rb-appbar-enter`・`tb-appbar-enter`

## 3. 欄で Return を押したとき

  - 訂正:

  - 訂正:

- **BAR-12** ★検索するのは、検索と置換のタブが**テキストか正規表現のときだけ**（2026-10-03・最初の実機確認での作者の決定）。
  ほかのタブでは、Return は止めるが**何も検索しない**。パネルが開いていれば、メッセージ欄に
  `Application Bar link: Return searches on the Text and GREP tabs only - nothing was searched.`（パネルは開かない）
  （2.0 から：KFC の「QR Code」タブのときだけは別で、欄は空を映し、Return は欄が空でも QR コードの一覧（打った文字は使わない）＝第18章 QR-22。）

- **BAR-13** テキスト・正規表現のときの順番 ――

## 4. 欄が見えないとき・OFF・終了

- **BAR-15** InDesign は、**ホーム画面が出ている間**、アプリケーションバーの**検索欄を隠す**（2026-10-04 実測）。
  ブックを付けて起動するとホーム画面が残り、欄は隠れたまま。文書を開くか、ブックを開き直すとホーム画面が消えて欄が出る
  （10-02 に「メニューを2段にしないと入らない幅のとき」と書いたのは、同じホーム画面の間に見たものだった）。
  そのとき ON にすると、メッセージ欄は `Application Bar link: on - works while the Application Bar's search field is shown.`（SET-09）。
  隠れた欄でも、仕掛けそのものは働く（2026-10-03 実測）。
  InDesign だけを起動したときも、ホーム画面の間は欄が隠れる（2026-10-22 実測）。⚠最後の文書を閉じた後に戻ってくるホーム画面では、隠れるときと隠れないときがある（2026-10-22＝4回のうち1回だけ隠れた）。
  - 訂正:

- **BAR-16** OFF にすると、Return を見る仕掛けと、欄を書き直す仕掛けを外し、検索と置換を追いかけるのもやめる。まだ走っていない検索・書き直しは取りやめる。
  欄に映していた文字は、消さずにそのまま。
  - 訂正:

- **BAR-17** ★Return を見る仕掛けは、**ON の間だけ**置く（InDesign のメインのスレッドだけを見る。ほかのアプリケーションには掛からない）。
  - 訂正:

- **BAR-18** InDesign を終了するとき、仕掛けをすべて外してから終わる。
  - 訂正:

## ⬜ この章で未確認

この章を書くにあたって**確かめていない**もの。「書いていない＝そういう決まりが無い」ではない。

- BAR-08：**人が欄に打ち込んでいる最中**に書き直さないことは、コードの注から読んだもの（打ち込みは書き直しの知らせにならない）。人が打ち込む形では測っていない。⚠**外から WM_SETTEXT で書いた文字**は InDesign の書き込みと見分けられず、次の idle で検索と置換のクエリーに書き直される（2026-10-22 実測＝10-03 の「one」の正体。人の打鍵は WM_SETTEXT ではないので当たらない見込み）。
- BAR-16：OFF にした後も、欄は映していた文字のまま（2026-10-22 実測）。いつ InDesign 自身の「Adobe Stock」に戻るか（次に InDesign が欄に書いたとき＝メニューを使ったとき、の見込み）は、人の操作が要るので測っていない。
- BAR-13：文書もブックも無いときの Return は、検索がメッセージ欄に `No open document to search.` と出して断る（2026-10-22 実測・検索と置換の文字はそのまま）。範囲（選択など）に対象が無いときは測っていない（オブジェクトのタブは BAR-12 で止まる＝2026-11-07 からはテキストの検索）。
