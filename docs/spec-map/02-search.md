# 02. 検索 ― 何を探し、いつ断るか

> コード地図での位置: ブロック **8**（検索エンジン `model/KBSSearchEngine.*`）。範囲の決まり方そのものは第3章、行に何が書かれるかは第4章。
> 訂正の書き方は [00-index.md](00-index.md)。

---

## 1. 何を探すか

- **FIND-01** 検索条件はすべて、本体の「検索と置換」で**いま選ばれているタブ**のものを使う ――
  検索文字列（字形タブなら検索字形とそのフォント、文字種変換タブなら検索文字種）、
  オプション（大文字小文字・単語単位・かな・全角半角）、検索形式（Find Format）。KFC が自分で決める条件は無い。
  - 訂正:

- **FIND-02** **検索形式だけ**の検索（検索文字列は空で、段落スタイルなどだけを指定）もできる。
  「探すものがあるか」は KFC が自分で判定せず、本体自身の判定（`IsThereSomethingToFind`）に聞く。
  - 訂正:

- **FIND-03** 「検索と置換」の範囲の5項目 ―― Include Master Pages（親ページ）・Locked Layers・Hidden Layers・Locked Stories・Footnotes ――
  も**ダイアログのとおり**に従う。KFC が独自に入れたり外したりはしない。
  ⚠ロックされたレイヤー・ストーリーの一致は**一覧には出るが、置換はされない**（本体でも「検索のみ」の項目のため）。→ 第6章
  - 訂正:

- **FIND-04** 一致を KFC が自分で判定することはない。本体の検索コマンド（`kFindTextCmdBoss`）と本体の検索の歩き手（text walker）をそのまま使う
  ＝**一覧に出るのは、本体の検索が見つけるのと同じ一致**。
  - 訂正:

- **FIND-05** 変更履歴で**削除された文字は検索しない**（本体の検索も 0 件で、同じ。2026-08-17 に実機で確認）。
  - 訂正:

- **FIND-06** あふれた文字（overset）・表のセルの中・（Footnotes の項目が ON なら）脚注の中も、一致に入る。
  利用者が触れない内部のストーリーは検索しない（本体の検索の対象外と同じ）。
  - 訂正:

## 2. 対応するタブ

- **FIND-07** 検索できるのは **Text・GREP・Glyph・Transliterate** の4つのタブ。
  **Object・Colour のタブでは Find in … が灰色**になり、それでも（スクリプトなどから）押されたら
  `The Find/Change dialog is on the Object tab. This panel lists text - use InDesign's own Find/Change.` と断る。
  - 訂正:

- **FIND-08** ★文字種変換（Transliterate）のタブも、ほかのタブと同じに検索・置換する（2026-08-05 の決定＝本体のパネルの設定どおりに）。
  このタブは日本語版の InDesign にしか出ない。
  - 訂正:

## 3. いつ断るか

- **FIND-09** 断る理由は**下の順に**調べ、最初に当たったもので断る。
  ★**断ったときは前の結果をそのまま残す** ―― パネルの一覧も、開いていた章も、検索と置換の設定も一切触らない
  （2026-08-03 に、断るだけの検索が前の結果を消していた不具合を直して、この順番になった）。
  - 訂正:

- **FIND-10** ①**ほかの実行が走っている** → `Another Kohaku Find/Change run is already in progress.`
  （検索の最中にもう一度検索が来たときは `A search is already running.`）。
  - 訂正:

- **FIND-11** ②**タブが Object／Colour** → FIND-07 の文。
  - 訂正:

- **FIND-12** ③**探すものが無い** → `No search text set on the Text tab. Type what to find in Edit > Find/Change, then search again.`
  字形タブは `No glyph set on the Glyph tab.`、文字種変換タブは `No character type set on the Transliterate tab.` で始まり、
  後半は `Choose one in Edit > Find/Change, then search again.`（選ぶものなので「打つ」ではなく「選ぶ」）。
  ⇒ **どのタブに無いのかを名指しする**（タブごとに別の検索文字列を持つので、ほかのタブに入っていても役に立たない）。
  - 訂正:

- **FIND-13** ④**Book Scope が ON なのに「検索:」が Document 以外** →
  `Book Scope is on, and Search: is Story. Set Search: to Document in Edit > Find/Change, or turn Book Scope off.`
  ★黙って Document として読み替えることはしない（「範囲を利用者の後ろで変えない」）。
  ⚠「検索:」は**今の選択で見たとき**の値で判定する ―― 何も選んでいない Story はダイアログでも Document と表示されるので、断らない。
  - 訂正:

- **FIND-14** ⑤**Book Scope が OFF で、「検索:」が KFC の知らない値**（スクリプトでしか設定できない「ストーリーの一覧」など）→
  `Search: in Edit > Find/Change is set to something this panel cannot follow. Set it to Document, All Documents, Story, To End of Story or Selection.`
  - 訂正:

- **FIND-15** ⑥**Book Scope が ON でブックが開いていない** → `Book Scope is on, but no book is open.`／
  **章が1つも無いブック** → `That book has no chapters.`
  ⑦**Book Scope が OFF で前面の文書が無い** → `No open document to search.`
  - 訂正:

- **FIND-16** ⑧**タブを確定し直せなかった**（FIND-19）→ `The Find/Change tab could not be set - nothing was searched. Try reopening Edit > Find/Change.`
  - 訂正:

- **FIND-17** メニューで**灰色になるのは ①②⑥⑦ だけ**。③④⑤⑧ は Find in … を押せるが、押すとメッセージ欄で断る
  （灰色にするのは「押しても何も始められない」ときだけ。理由を言えるものは押させて言う）。
  - 訂正:

- **FIND-18** ★断る理由をすべて通り過ぎた所（コード上の「commit point」）で、**前の結果は消える** ――
  この後に何も見つからなくても、途中で取り消しても、前の一覧は戻らない。
  - 訂正:

## 4. 検索の前に KFC がすること

- **FIND-19** 検索の直前に、**今のタブを今と同じ値で確定し直す**（字形タブなら検索字形、文字種変換タブなら検索文字種、どのタブでも置換モードも）。
  パネルから動かした検索は「確定されたタブ」で走るので、これをしないと画面が字形タブでも「テキスト」として走る（2026-07-30 に実際に起きた）。
  書くのは読んだ値そのままなので、**利用者の設定は変わらない**。
  - 訂正:

- **FIND-20** ★検索の間だけ**検索方向を前向き**にし、終わったら利用者の設定に戻す（取り消し・失敗を含め、どう終わっても戻す）。
  断られた検索では方向に一度も触らない。
  - 訂正:

- **FIND-21** ⚠検索の歩き手（text walker）は、本体の「検索と置換」ダイアログと**共有**している。
  そのため、ダイアログで「次を検索」を進めていた途中でパネルから検索すると、その途中の位置は捨てられ、次の「次を検索」は先頭から始まる
  （コードからの推論。実機では測っていない）。
  - 訂正:

- **FIND-22** 検索に使った条件（タブ・検索文字列・すべてのスイッチ・検索形式）を、結果と一緒に覚えておく。
  ストーリーごとの「版」（本体の変更カウンタ）も覚える。どちらも、あとで置換するときに「条件も文書も変わっていないか」を確かめるため。→ 第6章
  - 訂正:

## 5. 範囲ごとの歩き方

範囲が**どれになるか**は第3章。ここは、決まった範囲を**どう歩くか**。

- **FIND-23** **Document** ＝前面の文書を、**カーソルの位置に関係なく先頭から**全部。
  ★2026-10-02 の決定（カーソルのある位置から歩くと、一覧の行の並びがカーソルの場所で変わってしまったため）。
  - 訂正:

- **FIND-24** **All Documents** ＝開いている文書を1つずつ、それぞれ先頭から。**窓の無い文書も含む**（本体の All Documents と同じ・2026-09-29 に実測）。
  ただし、KFC がブックの検索のために窓なしで開いて保持している章は含めない（利用者が開いた文書ではないため）。
  - 訂正:

- **FIND-25** **Story** ＝ダイアログ自身の Story の範囲に「どのストーリーか」を聞き（最初の一致で決まる）、そのストーリーを先頭から全部。
  一致が1つも無ければ、何も出ない。
  - 訂正:

- **FIND-26** **To End of Story／Selection** ＝ダイアログ自身の範囲のまま、選択の位置から前へ。**先頭へは戻らない。**
  - 訂正:

- **FIND-27** ★選択がその「検索:」を許さないとき（Story なのに何も選んでいない、Selection なのにカーソルだけ、To End of Story なのにカーソルが無い）は、
  **本体と同じく文書全体を検索し、メッセージ欄にそう書く**
  （例 ` Search: is Story, but no text or text frame is selected - the whole document was searched, as Edit > Find/Change does.`）。
  2026-09-29 の決定（最初は断る作りだったが、本体の動きを測って本体に合わせた）。
  - 訂正:

- **FIND-28** **Book** ＝ブックの章を並び順に1つずつ。開いていない章は窓なしで開き、歩き終えたら**その場で閉じて返す**
  （1度に保持する章は1つだけ）。→ 第3章
  - 訂正:

## 6. 進捗と取り消し

- **FIND-29** 検索中は**文書1つでも進捗バーが出る**（ストーリーの多い文書は1つでも長いため）。
  題はブックなら `Searching book...`、それ以外は `Searching...`。行には `Chapter 3 / 12 - ch03.indd`（All Documents は `Document 2 / 5 - …`）。
  - 訂正:

- **FIND-30** バーの Cancel は、**一致のある次のストーリーへ移るとき**と**章と章の間**で聞く
  ★（2026-10-02 の決定＝「章の間だけ」と「バーが動くたび」の間を取った）。
  ⚠歩き手が KFC に戻ってくるのは一致を見つけたときだけなので、一致の無い長いストーリーを歩いている間は、次の一致まで止まらない。
  - 訂正:

- **FIND-31** 取り消すと**途中までの結果は捨てる**（途中までの一覧を、全部の一覧に見せないため）。メッセージ欄は `Search cancelled.`。
  前の結果も戻らない（FIND-18）。KFC が開いた章は閉じて返す。
  - 訂正:

## 7. 結果の並びとメッセージ欄

- **FIND-32** 一覧に入るのは、**一致が1つ以上あった文書（章）だけ**。空の章の行は作らない。
  - 訂正:

- **FIND-33** 章の中の並びは**ページ順**。同じページの中は歩いた順。あふれ（ページの無い一致）は最後。（行の番号の付け方は第4章）
  - 訂正:

- **FIND-34** 見つかったときのメッセージ ――
  ブック `N hit(s) in M of T chapter(s).`（M＝一致のあった章、T＝調べた章）／All Documents `N hit(s) in M of T document(s).`／
  それ以外 `N hit(s).`（Story・To End of Story・Selection は ` in the story` ` to the end of the story` ` in the selection` が付く）。
  最後に ` Right-click the book or a document row for a menu.` を付ける。
  ★**文書名・ブック名は書かない**（2026-08-03 の決定＝すぐ下の木の最初の行に出ているので、欄を食うだけ）。
  - 訂正:

- **FIND-35** 見つからなかったときは、**何を検索したかを名前で書く**（下に木が無いので） ――
  `No matches in book "X".`／`No matches in T open document(s).`／`No matches in document "X".`
  - 訂正:

- **FIND-36** ★調べ切れなかった章は、見つかったかどうかに関係なく**名前つきで書き足す**（「一致が無かった章」と見分けがつかなくなるため） ――
  開けなかった章／検索できなかった章（`could not be searched` と理由）／途中で止まった章（`stopped with a search error - the rest of each was never searched.`。止まる前の一致は一覧に残る）／
  KFC が開いたのに閉じられなかった章。名前は3つまで、それ以上は `...`。
  - 訂正:

- **FIND-37** 安全の上限（5,000 行＝パネルに描く上限と同じ・GEN-34）で止まったときは ` Stopped at the 5000 safety limit - narrow your search.` を書き足す。
  上限で止まると、それより先の章・文書は歩かない。（2026-10-04 までは上限が 10,000 で、後ろに ` Showing first 5000 in the panel.` も付いていた。）
  - 訂正:
