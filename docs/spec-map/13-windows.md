## 1. Translucent Panel（このパネルを半透明に）

- **WIN-01** ON にすると、**ポインタがパネルの外にある間、パネルが薄くなる**（不透明度 77＝約30%）。ポインタがパネルに乗ると、**くっきり戻る**。
  「パネルの上」には、パネルの中身だけでなく、タブの帯（`Kohaku Find/Change - …`）と、上の細い帯（`<<`・`×`）も入る。
  - 訂正:

- **WIN-02** ★薄さは 77 の1つだけ（KCM（当時の KESCM）で、128＝50% では濃すぎるという作者の判断で決めた数）。スライダーも段階も無い。
  0 には近づけない（0 の部分はポインタが素通りするので、乗っても戻らなくなる）。
  - 訂正:

- **WIN-03** 効くのは、パネルが**浮いているとき**と、アイコンから**引き出したとき**だけ。
  ドックに入って開いている間は、何も変わらない（設定は立ったままで、浮かせた瞬間に効く＝SET-07）。
  - 訂正:

- **WIN-04** ★ON の間は、パネルの**影を消す**（ポインタが乗ってくっきりしているときも）。
  影だけ濃く残ると重く見えるため（KCM（当時の KESCM）2026-07-29 の報告「ドラッグ中は良いのに、離すと影が濃い」）。
  - 訂正:

- **WIN-05** ★パネルが**自分で出したもの**（右クリックメニュー・ツールチップ）がパネルの上にある間は、くっきりのまま（2026-08-05 の作者の報告で直した＝それまでは、文書の行を右クリックすると薄くなった）。
  その代わり、**InDesign の別の窓**がパネルを覆っている間も、くっきりのままになる（ポインタがパネルの四角から出れば直る）。
  - 訂正:

- **WIN-06** 別のアプリケーションに切り替えると、薄くなる（ポインタをタブの帯に置いたまま切り替えても）。
  - 訂正:

- **WIN-07** **浮いたパネルをいくつかまとめた組**の中にあると、組ごと薄くなる（組は1つの窓なので）。
  KFC のパネルを組から抜く・ドックに入れると、残った組の窓は**くっきりに戻す**（2026-10-03 に直した＝それまでは薄いまま残り、OFF でも戻らなかった）。
  - 訂正:

- **WIN-08** パネルを開き直す・ドックから出すと、InDesign が窓を作り直すので、**約0.4秒の間、何度か当て直す**。
  - 訂正:

- **WIN-09** OFF にすると、くっきりに戻し、影も戻す。ドックに入れたまま OFF にしても、薄い窓は残らない（ドックに入れたときに、その窓は無くなっている）。
  - 訂正:

## 2. 検索と置換ダイアログの見つけ方（下の2つのトグルに共通）

- **WIN-10** InDesign の**検索と置換ダイアログ**は、題名でも窓の種類でもなく、**中のパネルの番号**（WidgetID）で見つける。
  ⇒ どの UI 言語でも同じように効く（題名は訳されるし、窓の種類はほかのダイアログと同じなので使えない）。
  - 訂正:

- **WIN-11** ダイアログは**開くたびに作り直される**ので、開いたときに当て直す。
  ★その起動で**初めて**開いたダイアログは、開いた瞬間にはまだ見分けがつかないことがあるので、**開いてから1秒ほど、何度か探し直す**
  （2026-10-03 に直した＝それまでは、Translucent Find/Change だけ ON のとき、その起動の最初のダイアログが薄くならなかった）。
  - 訂正:

- **WIN-12** 探し直すのは、新しく開いた窓が**検索と置換かもしれないとき**だけ（文書の窓が開いたときは探さない＝2026-10-03）。
  - 訂正:

## 3. Translucent Find/Change（検索と置換ダイアログを半透明に）

- **WIN-13** ON にすると、InDesign の**検索と置換ダイアログ**が、ポインタが外にある間**薄くなる**（パネルと同じ 77）。ポインタが乗るとくっきり戻る。
  別のアプリケーションに切り替えると薄くなる（ダイアログには、ポインタが離れた知らせが来ないので、これがただ1つのきっかけ）。
  - 訂正:

- **WIN-14** そのために、KFC は**ダイアログの窓に重ね描きの印（`WS_EX_LAYERED`）を付ける**（パネルと違い、もともと付いていない）。
  付けても、文字・枠・ボタンに何の影響も無かった（作者の確認・2026-08-04）。
  - 訂正:

- **WIN-15** OFF にすると、くっきりに戻し、**自分が付けた印だけを外す**（もともと印の付いていた窓からは外さない）。
  ダイアログが閉じていても、OFF の後始末はする。ダイアログが**最小化されている**ときは、印を外すだけにして、枠の描き直しはしない（戻したときに全体が描き直される＝2026-10-03 実測）。
  - 訂正:

- **WIN-16** ダイアログが閉じているときに ON にすると、メッセージ欄に `Translucent Find/Change: on - applies when the Find/Change dialog is open.`（SET-09）。次に開いたときに効く。
  - 訂正:

## 4. Minimizable Find/Change（検索と置換ダイアログに最小化ボタン）

- **WIN-17** ON にすると、InDesign の**検索と置換ダイアログに最小化ボタン**が付き、閉じる代わりに**タスクバーへしまえる**。
  - 訂正:

- **WIN-18** ★最小化したダイアログは**タスクバーに出る**（2026-08-12 の作者の選択＝そうしないと、画面の左下に題名の帯だけの小さな窓が残る）。
  - 訂正:

- **WIN-19** SDK には、できている窓の飾りを変える口が無いので、Windows の窓の形を直接3つ変える ――
  最小化ボタンを付ける／道具窓の印を外す（これを外さないとボタンが描かれない）／タスクバーに出す印を付ける。
  それぞれ**もともと付いていたか**を覚えておき、OFF では**自分が変えたものだけ**を戻す。
  - 訂正:

- **WIN-20** ダイアログが**最小化されている間は付けない**（最小化した窓の枠を作り直したら、窓ごと消えたことがある＝2026-08-12）。
  ダイアログを元に戻してから、トグルを切り替え直せば（OFF→ON）付く。
  - 訂正:

- **WIN-21** OFF にしたときダイアログが**最小化されていたら、先に元に戻してから**形を戻す（しまったまま道具窓に戻すとタスクバーから消え、どこからも出せなくなるため）。
  - 訂正:

- **WIN-22** ★戻す前に、**それがまだ自分が形を変えたダイアログか**を確かめる（同じプロセス・同じ窓の種類・一番上の窓・自分の印）。
  閉じた後に同じ番号が別の窓に使い回されると、その窓の飾りを書き換えてしまうため（2026-10-03 に直した）。
  - 訂正:

- **WIN-23** ★フライアウトの `Open Find/Change...` は、ダイアログが**最小化されていれば元に戻す**（トグルが OFF でも・誰が最小化したのでも＝2026-10-03 の作者の決定）。
  InDesign の 編集 > 検索と置換 は、開いているダイアログを（最小化中でも）**閉じる**ので、KFC のメニューから押すと捨てられたように見えたため。
  - 訂正:

## 5. 3つに共通

- **WIN-24** 3つとも Windows の窓を直接扱う機能で、**最初は OFF**。Save Panel Settings を押したときだけ保存され、次の起動で戻る（SET-15・SET-16）。
  - 訂正:

- **WIN-25** ★**OFF の間は何もしない**（ポインタの位置も見ない＝2026-07-29 の作者の規則）。
  ポインタの動きを見る Windows の仕掛け（イベントのフック）を置くのは、半透明のトグルのどれかが ON の間だけ。
  InDesign 自身の知らせ（パネルの出し入れ・窓の開け閉め）は聞いているが、OFF なら何もせずに返る。
  - 訂正:

- **WIN-26** InDesign を終了するとき、検索と置換ダイアログに付けた印と形を**戻してから**終わる（ほかのアプリの窓に、自分の印を残さないため）。
  ⚠実際には、InDesign は終了の後始末より先にダイアログを閉じるので、戻す相手はもういない（2026-10-03 実測）。
  - 訂正:
