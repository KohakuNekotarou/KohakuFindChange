## 1. パネルの開き方と名前

- **PNL-01** パネルは **ウィンドウ > Kohaku Plug-Ins > Kohaku Find/Change** から開く（GEN-40）。メニューの場所はここだけ。
  ⚠初めて入れたときは、本体の既定のワークスペースがパネルを隠しているので、このメニューから開く。
  - 訂正:

- **PNL-02** タブの名前は **`Kohaku Find/Change - <タブ> - <範囲>`**（GEN-27）。パネルが開いている間、次のときに書き直す ――
  パネルを見せたとき・検索と置換の設定が変わったとき（ダイアログのタブを押したときも）・**選択が変わったとき**（「検索:」の意味が選択で変わるので）・
  Book Scope を切り替えたとき・検索のたび。名前が今のと同じなら書かない（キャレットの1歩ごとに書き換えないため）。
  - 訂正:

- **PNL-03** ★選択が変わったときもタブ名を追いかける（2026-10-03 に直した＝それまでは、ダイアログを閉じたまま選択を変えると、次の検索が使わない範囲をタブが言い続けていた）。
  - 訂正:

- **PNL-04** タブの名前のつなぎは ASCII の ` - `（長いダッシュは、この大きさのタブでは隙間に見えるので＝2026-07-28 の決定）。範囲は `Doc` などに略さない（2026-08-01・09-27 の決定）。
  - 訂正:

- **PNL-05** InDesign を終了するとき、タブの名前を `Kohaku Find/Change` に戻す（範囲つきの名前をワークスペースが覚えないように）。
  - 訂正:

- **PNL-06** パネルを細く畳んだときのタブには、名前の代わりに KFC の小さな絵（`KohakuFindChangeTab.png`）が出る。
  - 訂正:

## 2. 絵

- **PNL-07** メッセージ欄の横の絵は**3枚**で、状態で入れ替わる ――
  何も実行していない＝猫（`Kohakuneko_OFF32.png`）／検索か Show Changes をした＝探している猫（`KohakuFind32.png`）／
  **Change Checked で置換して報告が出ている**＝置換している猫（`KohakuChange32.png`）。
  結果が消えると（文書を閉じた・新しい検索）、それに合った絵に戻る。
  - 訂正:

- **PNL-08** ⚠「置換している猫」は **Change Checked の後だけ**。行のメニューの Replace では一覧が作業リストのままなので（REP-25）、探している猫のまま。
  - 訂正:

- **PNL-09** 絵に**マウスを乗せると KFC のホームページの URL**（`https://github.com/KohakuNekotarou/KohakuFindChange`）が出て、
  **クリックすると、そのページをブラウザで開く**（文書には何もしない）。
  - 訂正:

## 3. メッセージ欄の大きさ

- **PNL-10** メッセージ欄は**4行**ぶんの高さ（止まった置換の文が128文字あり、3行では切れたため＝2026-08-10）。
  - 訂正:

- **PNL-11** ★1行の高さは、**UI 言語のパレットの文字の高さ**から決める（英語は12px、日本語は18px で、1つの数では片方が切れる＝2026-08-06 の報告。
  2026-10-02 から、表ではなく文字そのものに聞く）。日本語 UI では 4×18＝72px。パネルを見せるたびに測り直す。
  - 訂正:

- **PNL-12** 4行に入らない長い文は、最後に「…」が付いて切れる（メッセージは下限の幅で4行に収まるように書いてある）。
  - 訂正:

## 4. パネルの大きさ

- **PNL-13** パネルを開いたときの高さは **360px**（リソースの値）。
  - 訂正:

- **PNL-14** ★**狭くできる下限**がある ―― 幅は **266px**（ふだんの大きさで測った値＝2026-08-07）、高さはメッセージ欄の高さに合わせて動く
  （欄が高い日本語 UI では、結果の行が下限で消えないよう、下限も高くなる）。それより小さくはドラッグできない。
  - 訂正:

- **PNL-15** ドラッグで高さを変えると、**結果の行がちょうど何行分かになる高さ**に丸める（一番下に、切れた行が見えないように＝2026-08-09）。1行は19px。
  ⚠開いたときの高さ（360）と、日本語 UI でメッセージ欄が高くなった直後は丸められていないので、一番下に切れた行が見えることがある（一度ドラッグすれば直る）。
  ドックの中の高さはドックのものなので、KFC が書き戻すことはしない。
  - 訂正:

## 5. How to Use と About

- **PNL-16** フライアウトの **How to Use...** は、使い方の説明を、**スクロール・選択・コピーのできる窓**で出す（題は `Kohaku Find/Change - How to Use`）。
  - 訂正:

- **PNL-17** ★説明は、UI 言語が日本語なら日本語、それ以外は英語（2026-08-05 の決定＝featureSet ではなく UI 言語で決める）。
  中身は8節 ―― 免責／検索（Find in …）／検索範囲（Book Scope）／結果の見方／置換（Change Checked）／Show Changes／ブックパネル（Remember Book Panel Placement）／アプリケーションバーの検索欄。
  - 訂正:

- **PNL-18** スクリプトの窓が出せないときは、ふつうのアラートで同じ文を出す（先頭に `Kohaku Find/Change - How to Use` を付ける＝アラートには題が無いので）。
  - 訂正:

- **PNL-19** ★**About** は**名前と版数だけ**（`Kohaku Find/Change version 1.3.0`）で、どの UI 言語でも同じ（2026-08-09 の決定＝説明・謝辞・URL は外した）。
  パネルメニューの末尾 `About This Plug-in...` と、本体の About のメニューの下から開く。
  - 訂正:
