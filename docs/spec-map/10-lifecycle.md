## 1. 文書を閉じたとき

- **LIFE-01** ★**文書の結果**（Book Scope OFF で検索した結果）は、**その文書を閉じると消える**（`Results cleared - the document was closed.`）。
  閉じた文書の行を残すと、クリックで黙って開き直し、Change Checked で書き込んでしまうため。
  - 訂正:

- **LIFE-02** ★**All Documents の結果**は、閉じた**その文書の行だけ**が消え、ほかの文書の行・チェック・取り消しの追従は残る（2026-09-29 の決定）。
  `<文書名> was closed - its rows are gone. The other documents' rows stay.` 一覧の最後の文書を閉じたときは、LIFE-01 と同じく全部消える。
  - 訂正:

- **LIFE-03** ★**ブックの結果**は、章を1つ閉じても**消えない**（章はファイルから開き直せるので、20章の結果を1章のために捨てない）。
  - 訂正:

- **LIFE-04** 閉じる途中で保存の確認が出て、利用者が**キャンセル**したときは、何も消えない（閉じる知らせは、閉じると決まってから届く＝2026-08-08 実測）。
  - 訂正:

- **LIFE-05** 一度も保存していない文書を、保存せずに閉じたときも、ふつうに結果が消える（2026-08-08 実測）。
  - 訂正:

- **LIFE-06** **「復帰」**（ファイル > 復帰）も「閉じる」として届くので、その文書の結果は消える（文言は `the document was closed`・2026-10-03 実測）。
  - 訂正:

- **LIFE-07** どの文書を閉じても、KFC はその文書について持っていたもの（保持中の章の一覧・ジャンプの印・取り消しの耳）を、結果とは別に**必ず**手放す
  （閉じた文書のアドレスが、次に開く文書に使い回されて取り違えないため）。
  - 訂正:

- **LIFE-08** 検索・置換・Show Changes が**走っている間**に閉じられた文書の結果は、その場では消さない（走っている実行が、終わったときに自分の結果を出すので）。
  - 訂正:

- **LIFE-08b** PDF などを**後ろで書き出す**とき、InDesign は文書の写しを使って、終わると閉じる。その写しが閉じても、**結果は消えない**（閉じる知らせのうち、後ろの処理のものは受け流す＝2026-10-04 実測）。

## 2. ブックを閉じたとき

- **LIFE-09** ★**ブックの結果**は、**そのブックを閉じると消える**（`Results cleared - the book was closed.`）。
  一致が0件だったブックの検索でも、ブックの行が残っているので、それも消える。
  - 訂正:

- **LIFE-10** ブックを閉じると、KFC がそのブックのために開いて、**窓の無いまま残っている章**があれば、それも**閉じて返す**
  （一覧に何が出ていても。窓の無い章は、残すと `.indd` のロックが残り、利用者には見えも閉じもできないので）。
  ブックの結果を出していなければ、一覧には触らない（文書の結果を出していれば、そのまま）。
  ⚠**ふつうは残っていない** ―― 検索・Show Changes・Change Checked は、窓なしで開いた章を、終わるまでに閉じて返すか、窓を付けて利用者に渡す（SCOPE-10・REP-24）。
  窓の無いまま残るのは、**失敗したときだけ**：
  ①ジャンプや文書の行のクリックで閉じた章を開き直したのに、窓を開けなかった（`Cannot bring that chapter's window to the front.`）
  ②置換が書いたのに窓を開けなかった（` … chapter(s) were changed but could not be shown - open them from the book panel to save them.`）
  ③本体が閉じるのを断った。
  ②は置換が入って未保存なので、ブックを閉じても**閉じない**（閉じると黙って消えるため・SCOPE-18）。このときの「返す」は、①③の取り残しを片づける安全網。
  - 訂正: ✅2026-10-04 回答 → **ふつうは無い。失敗したとき（窓を開けなかった・閉じるのを断られた）だけ残る**。どんなときに残るかを本文に書き足した（地図の書き落とし＝A）

- **LIFE-11** 「閉じたのはどのブックか」を InDesign は知らせてこないので、KFC は**ブックが閉じるたびに「検索したブックがまだ開いているか」を聞く**。
  閉じる知らせの瞬間はまだ開いているように見えるので、**約0.3秒後**に聞く。ほかのブックが閉じただけなら何もしない。
  - 訂正:

- **LIFE-12** ブックを閉じたのが検索・置換・Show Changes の**走っている最中**なら、終わるまで待ってから聞く。
  - 訂正:

- **LIFE-13** ★⚠**ブックを別名で保存した後**は、ブックの行のクリックが `That book is no longer open.` と言い、**別のブックを閉じただけで一覧が消える**
  （KFC が覚えている「検索したブック」のパスが古いままになるため）。章の行のジャンプと置換は、章のファイルで引くので動く。
  ＝**2026-10-03 の決定でいまのまま**（別名で保存するのはまれなので。ブックには ID が無く、直すなら別名で保存のコマンドを横取りすることになる）。
  - 訂正:

## ⬜ この章で未確認

この章を書くにあたって**確かめていない**もの。「書いていない＝そういう決まりが無い」ではない。

- LIFE-11：0.3秒後に「まだ開いている」と答える遅いマシンがあるかは測っていない（その場合は次のブックの閉じる知らせまで消えない）。
- LIFE-13：ブックを別名で保存した後に、そのブック自身を閉じたとき一覧が消えるかは、この章のためには確かめていない（パスが古いので、閉じる前から「開いていない」と答える見込み）。
- LIFE-06：復帰の保護停止（InDesign が落ちた件）は KFC が原因ではないと分かっているが、復帰と KFC の組み合わせは数回しか試していない。
- 文書を**別名で保存**したときの文書の結果（パスが変わる）は、この章では確かめていない（文書の結果は文書そのもので引くので、影響しない見込み）。
