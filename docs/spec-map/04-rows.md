## 2. 各行に書かれるもの

- **ROW-06** **ブックの行**＝`<ブック名>  (N/M checked)`。M＝一覧の全ヒットの数、N＝チェックが付いている数（どちらもスクロールの外の行を含む）。
  チェックボックスの無い一覧（置換の報告・記録から作り直した一覧）と、0件のときは `(M)` だけ。
  - 訂正:

- **ROW-07** **文書の行**＝`<文書名>  (N/M checked)`（数え方はブックの行と同じ）。
  All Documents で**窓の無い文書**は、名前の後に ` (no window)` が付く（ジャンプで窓が開けば、次の描き直しで消える）。
  - 訂正:

- **ROW-08** ⚠M には**ロックされてチェックできない行も数える**。そのため、チェックを全部付けても N が M に届かないことがある
  （ほかの場所で言うヒットの数と食い違わせないため、わざとそうしてある）。
  - 訂正:

- **ROW-09** **ストーリーの行**＝`P<最初の一致のページ>  <ストーリーの書き出し>  (N/M checked)`。
  書き出しは**最初の24文字**。段落の終わりは ¶、強制改行は ↵、表は ▦ で見せ、字下げの空白や見えない文字は省く。
  ページが無いときは `P…` の代わりに `overset`。
  - 訂正:

- **ROW-10** **run の行**（Show Changes の一覧だけ）＝`<日付> <時刻>  (M)`＝その置換を走らせた時刻。→ 第8章
  - 訂正:

- **ROW-11** **ヒットの行**＝`[ ] P3(2)  前の文字[一致]後の文字` の形。頭は**ページの位置** ――
  `P<ページ名>`（セクションに従ったページの名前）。同じページに一致が2つ以上あるときだけ、`(n)` で何番目かを付ける。
  - 訂正:

- **ROW-12** あふれた一致は、**あふれの「＋」が付いているフレームのページ**で `P5(2) overset` と書く。
  どこにも置かれていない文字なら `overset` だけ。並びはページの無い一致が最後（FIND-33）。
  - 訂正:

- **ROW-13** ページの位置の後に、**状態の語**が付く（スペース区切り・いくつでも重なる・例 `P4(1) hidden locked`） ――
  **ふつうの色**＝`hidden`（非表示のレイヤー＝着いてもページに見えない）／`locked`（ロックされたレイヤー・ストーリー・アイテム）／
  `deleted`（ほかのチェックした行が消したオブジェクトと一緒に消えた）／`accepted`（変更を承認した）／
  `no track`（脚注の中で置換した＝変更履歴が無い）／`rejected`（記録から作り直した一覧で却下した行だけ）。
  **アクセント色**＝`missing`（検索したときの場所に文字が無い）／`refused`（本体の置換が断った）／`not replaced`（後注の終わりにあって書かなかった）。
  - 訂正:

- **ROW-14** ★状態の語は**省略しない**（`hid`・`lck`・`ov` などは読みにくいので取りやめ＝2026-08-04 の決定）。
  区切りに `+` を使わない（本体のあふれの印が `+` なので、`P5+locked` が「5ページ・あふれ」に読める）。
  - 訂正:

- **ROW-15** ★却下（Reject）で元に戻した行には、**語を付けない**（元の文字に戻り、チェックボックスが戻ることで分かる＝2026-09-27 の決定）。
  記録から作り直した一覧だけは、チェックボックスが無いので `rejected` と書く。
  - 訂正:

- **ROW-16** 本文の部分は、一致と前後を**合わせて50文字**に収める ―― 一致を先に取り、残りを前後で半分ずつ（片方が短ければ、余りはもう片方へ）。
  切った端には「…」。一致そのものが50文字を超えるときは一致の終わりを切って「…」とし、後ろの文字は出さない。
  前後は、一致が始まる段落・終わる段落の外へは出ない。★50 は 2026-08-10 の決定。
  - 訂正:

- **ROW-17** 一致は**本文の色**、前後は**薄い色**、ページの位置は本文の色、`missing` などは**テーマのアクセント色**で描く。
  ★色はすべて InDesign のテーマに従い、赤などの決め打ちの色は使わない（決定として記録あり）。
  - 訂正:

- **ROW-18** 行の中の改行は ¶（段落の終わり）と ↵（強制改行）で見せる（そのままだと前後の段落がつながって1つに読めるため）。
  ★表は ▦（U+25A6・KCM と同じ印・2026-09-29。`田` は使わない＝決定）。
  ★脚注・後注の参照・アンカー・ノンブルなど、**オブジェクトが乗っている文字は省く**（四角に見えるため＝2026-09-26 の決定）。
  - 訂正:

- **ROW-19** ¶・↵・▦ の印に変えるのは**描くときだけ**で、照合は元の文字で行う。
  置換やジャンプの前の「同じ一致か」は、**切っていない一致の全体**（の指紋）と、行の前後の文字（検索したときと同じ切り方で読み直す）で比べる
  （長い GREP の一致でも、描くために切った文字で照合していた頃のような取り違えは起きない）。
  - 訂正:

## 3. チェックボックス

- **ROW-20** チェックボックスがあるのは**ヒットの行だけ**。★最初はすべて外れている（GEN-02）。
  - 訂正:

- **ROW-21** チェックボックスが**無い**行 ―― 置換済みの行／ロックされた行／理由の語（`missing` など）が付いた行／
  置換の報告の中の行（却下で戻した行を除く）／記録から作り直した一覧の全部の行。
  ★無い行も、ページの位置の列はそろえたまま（ロックの多い一覧で左端がガタガタにならないよう＝2026-07-28 の決定）。
  一覧の**全部の行**にチェックボックスが無いときだけ、列を少し左へ寄せる（全行が一緒に動くので、そろいは崩れない）。
  - 訂正:

- **ROW-22** チェックボックスを押すと、メッセージ欄に `P3(2)  checked`（外すと `unchecked`）と出て、上の行の `(N/M checked)` がすぐ変わる。
  - 訂正:

- **ROW-23** Check All／Uncheck All は、フライアウトには無く、**行の右クリックメニュー**にある（2026-08-01 から）。
  **どこまで付くかは右クリックした行で決まる** ―― ブックの行＝ブック全体、文書の行＝その文書、ストーリーの行＝そのストーリー。
  チェックボックスの無い行には付けない。付けられる行が1つも無いときは灰色。
  - 訂正:

- **ROW-24** Check All の後のメッセージ欄 ―― ブック・文書の行では `<行の名前>  all checked`（`all unchecked`）、
  ストーリーの行では `This story: all checked.`（`all unchecked.`）。どの行に対してやったかを言うためで、数は行の側に出ている。
  - 訂正:

## 4. メッセージ欄

- **ROW-25** パネルの下のメッセージ欄は、**最後の結果を1つ**だけ出す（英語）。
  何も実行していないときは `Type what to find in Edit > Find/Change, then run Find from this panel's menu.`（GEN-03）。
  - 訂正:

- **ROW-26** パネルを閉じて開き直しても、**そのセッションの最後の文が戻る**。InDesign を再起動したら最初の文に戻る
  （前のセッションの文が残って見えていたのを、2026-08-02 の報告で直した）。
  - 訂正:

- **ROW-27** メッセージ欄は**3枚重ね** ―― ①最後の結果の文 ②置換した行を選んだときの `Source Text:` ③右クリックの理由。
  上の層は下の層を消さずに重なり、外れると下の層が戻る。**新しい結果の文が来ると、②③は消える**。
  - 訂正:

- **ROW-28** ②**Source Text**：置換した行を選ぶと、`Source Text:` の見出しに続けて、その行の前後の文字と、
  **置換で消えた元の文字**を出す（何も消さなかった置換＝挿入だけのときは縦棒）。
  隣り合って書いた置換は、まとめて元の文字を出す。元の文字は300文字で切って「…」。
  置換していない行を選ぶと消えて、①に戻る。★見出しの語は KCM と同じ（2026-09-29 の決定・それまでは `Before:`）。
  - 訂正:

- **ROW-29** ③**右クリックの理由**：ヒットの行・ストーリーの行を右クリックしたとき、その行の Reject／Accept ができないなら、
  **メニューを出す前に**理由をメッセージ欄に出す（例 `Reject Change: not for a match inside a footnote - Track Changes records nothing there.`）。
  理由は4通り＝脚注の中・文書が開いていない・置換した文字が非表示の条件の中・変更履歴がもう残っていない。
  メニューの項目が**すべて灰色**ならメニューは開かず（本体の振る舞い）、理由だけが残る。
  - 訂正:

- **ROW-30** ★右クリックの理由は「最後の文」にならない ―― 次に**理由の要らない右クリック**（ブック・文書・run の行、Reject できる行）をするか、
  **Source Text の無い行を選ぶ**と、下にあった文に戻る（2026-10-04 の決定＝それまでは最後の文として残り、次に右クリックした別の行の話に読めた）。
  - 訂正:

- **ROW-31** メッセージ欄の `&` は**そのまま**出る（手で描いているので、`A&B.indd` が `AB.indd` にならない・2026-09-29 から）。
  - 訂正:
