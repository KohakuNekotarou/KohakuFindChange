## 1. Book Scope の切り替え

- **SCOPE-01** 範囲は、フライアウトの **Book Scope** の1つのスイッチで決まる。ON＝ブックの全章、OFF＝本体の「検索:」が指すもの（GEN-24）。
  ★**切り替えはスイッチ1つだけ**で、範囲を選ぶ欄をパネルに持たない（決定として記録あり・日付は未確認）。
  - 訂正:

- **SCOPE-02** スイッチを切り替えても、**今の結果は消えず、章も閉じない**。変わるのは「次の実行の範囲」と、タブ名・検索コマンドの名前だけ。
  （切り替えの中で章を閉じると落ちる、と兄弟プラグイン KESCL で実際に起きたため、旗を立てるだけにしてある。）
  - 訂正:

- **SCOPE-03** 結果は**検索したときの範囲を覚えている**。検索の後で Book Scope を切り替えても、一覧の見え方（ブックの章の行が閉じて出るか）や
  Hide Previous Chapter が働くかどうかは、検索したときの範囲で決まる。
  - 訂正:

## 2. ON のとき、どのブックか

- **SCOPE-04** ★対象は**ブックパネルで前面に出ているタブのブック**。
  ⚠**「アクティブなブック」とは別**：ブックパネルでタブを選んでもそのブックはアクティブにならない（中の章に触ったときだけなる・2026-07-27 実測）。
  タブを選んで検索した人には、アクティブなブックではなく、見ているタブのブックが対象になる。置換で別のブックを書き換えないための決まり。
  - 訂正:

- **SCOPE-05** ブックパネルが見つからないとき（アイコンに畳まれている・パネルが閉じている）は、**アクティブなブック**を対象にする。
  UI プラグインが無いとき（バックグラウンドスレッド・InDesign Server）も同じ。
  - 訂正:

- **SCOPE-06** 閉じかけているブックは、対象にしない（閉じる通知の最中もブックは一覧に残っているので、「開いている」の印で判定する）。
  - 訂正:

- **SCOPE-07** 対象のブックが**無い**、または**章が1つも無い**ときは、検索も Change All in Book (No List) もメニューが灰色になる。
  それでも（スクリプトなどから）押されたら、前の結果を残したまま断る（`Book Scope is on, but no book is open.`／`That book has no chapters.`）。
  灰色の判定と実行は、同じ1つの関数（対象のブックを決める処理）に聞くので、食い違わない。
  - 訂正:

- **SCOPE-08** どのブックを検索したかは、**一覧の一番上のブックの行**にブック名で出る（ブックを検索したときだけ）。
  メッセージ欄には名前を書かない（FIND-34）。
  - 訂正:

## 3. 章の並びと、章の開き方

- **SCOPE-09** 章は**ブックの並び順**に、1つずつ処理する。
  - 訂正:

- **SCOPE-10** ★開いていない章は、**窓を出さず、警告も出さずに**（`kSuppressUI`）開き、歩き終えたら**その場で閉じて返す**。
  1度に開いている KFC の章は**1つだけ**（20章のブックでも、`.indd` のロックは1つずつ）。
  （以前は全部の章を開いたまま歩き、終わるまでロックが残っていた＝2026-08-02〜04 に改めた。）
  - 訂正:

- **SCOPE-11** ★警告を出さずに開く理由＝フォントやリンクが無い・別の版で保存された、などの**警告が出る章が、以前は黙って飛ばされていた**ため
  （その章は「一致の無い章」と見分けがつかなかった）。今は警告を出さずに開いて、ふつうに検索する。
  - 訂正:

- **SCOPE-12** **利用者が自分で開いていた章**は、その文書をそのまま歩く。KFC は**保持せず、閉じもしない**。
  「自分で開いていた章か」は、ブック自身に聞いた答えを、**章のファイルと同じか**で必ず確かめてから使う
  （確かめずに使っていた頃、別の章の文書を渡されて、その章の行がすべて missing になった＝2026-08-04 実測）。
  - 訂正:

- **SCOPE-13** 「同じファイルか」は**ファイルとして比べる**（パスの文字列では比べない・2026-09-27）。
  ★⚠ただし `subst` などで**別のドライブ名から開いた章**は同じと見なせず、「開けなかった章」として名前つきで報告される
  ＝★★**2026-09-28 の決定でいまのまま・10-04 に再確認＝再提案しない**（Win32 のファイル ID までは使わない）。
  理由＝起きるのはブックと章で別のドライブ名を使ったときだけ／失敗は安全側（章を取り違えて書かず、抜けた章は名前と理由つきで出る）／
  InDesign 自身も2つを別のファイルとして扱い、SDK にも「同じ実体のファイルか」を聞く口が無い。
  - 訂正: ✅2026-10-04 回答 → **正しさだけなら「よりよい」が、おすすめはいまのまま**（作者了承）。理由を本文に書き足し、★を1つ上げた

- **SCOPE-14** **古い版の InDesign で保存された章**は、メモリ上で変換された「ファイルの無い文書」として開く。
  KFC はそれを**元のファイルの章**と見なし（開いた元のファイルで照合する）、開いた直後は「未変更」として扱う
  ＝読むだけの検索では、閉じるのを妨げない。置換が入ったときだけ「変更あり」になり、閉じずに残す。
  ★変換の保存を促す・飛ばすなどの特別扱いはしない（2026-09-28 の決定）。
  - 訂正:

## 4. 開けなかった章

- **SCOPE-15** ★開けなかった章は**黙って落とさず**、メッセージ欄に**名前と、ブックが言う理由**を書く ――
  `  N chapter(s) could not be opened (ch02.indd: file is missing, ch05.indd: in use elsewhere).`
  理由の語は `file is missing`／`out of date`／`in use elsewhere`／`already open`／`missing plug-in data`。ブックが理由を言わないときは名前だけ。
  名前は3つまで、それ以上は `...`。
  - 訂正:

- **SCOPE-16** 開けなかった章があっても、**ほかの章は検索を続ける**。メッセージの「M of T chapter(s)」の T には、開けなかった章も数える。
  - 訂正:

## 5. 章の返し方 ―― 閉じるか、残すか

- **SCOPE-17** ★**KFC が閉じてよいのは、KFC が窓なしで開いた章（保持中の章）だけ**。利用者が開いた文書を KFC が閉じるのは、Hide Previous Chapter が ON のときのジャンプだけ（JMP-26＝検索したブックの章で、保存の要らないものに限る）。
  - 訂正:

- **SCOPE-18** 保持中の章でも、次のどれかなら**閉じない** ――
  ①**窓が付いた**（ブックパネルでダブルクリックした・ジャンプした・置換が入って窓を開けた）＝その瞬間から利用者のものになり、保持もやめる
  ②**保存していない変更がある**（置換が入ったのに窓が開けなかった章）＝閉じると黙って消えるので、保持したまま残す
  ③本体が閉じるのを断った。②③は保持の一覧に残り、後で返せる時が来たらまた試す。
  - 訂正:

- **SCOPE-19** 閉じられずに残った保持中の章は、**窓が無いので利用者には見えず、`.indd` のロックも残る**。
  そのため、実行の終わりにメッセージ欄へ名前を書く（`  N chapter(s) left open with no window (…).`）。
  - 訂正:

- **SCOPE-20** 保持中の章をまとめて返すのは ―― **次の検索（どの範囲でも）や Clear Results が前の結果を捨てるとき**・
  **そのブックが閉じられたとき**・**Change All in Book (No List) の終わり**（書いた章には窓を付けて渡し、書かなかった章とキャンセル・失敗のときの章は閉じて返す）。
  InDesign の終了では返さない（本体がすべての文書を閉じるので、一覧を忘れるだけ）。
  （Show Changes が結果を捨てるとき・Change Checked のキャンセルは、その機能ごと 2026-10-06 に外した。）
  - 訂正:

- **SCOPE-21** 検索が前の結果を捨てるときは、保持中の章を**その場で**閉じる（予約して後で閉じるのではない）。
  予約だと、閉じる前に All Documents の検索がその章を「利用者の文書」として拾ってしまったため（2026-10-02 に直した）。
  Clear Results は予約で閉じる（InDesign の手が空いたとき）。
  - 訂正:

## 6. OFF のとき、どの文書か

- **SCOPE-22** Document・Story・To End of Story・Selection が対象にするのは、**アクティブな文書**（本体の「検索と置換」が検索するのと同じ文書）。
  KFC が窓なしで開いている章は、アクティブにはなれないので、ここには来ない。
  - 訂正:

- **SCOPE-23** **All Documents** は開いているすべての文書（窓の無いものも含む）。ただし KFC がブックのために保持している章は除く（FIND-24）。
  ★⚠`.indd` を配置すると、その配置元が「窓もファイルも無い文書」として一瞬開いている一覧に載り、All Documents がそれも拾う。
  本体の All Documents も同じで、見分ける確かな印が無いため、**2026-10-04 の決定でいまのまま**（配置元のファイルは無傷）。
  - 訂正:

- **SCOPE-24** OFF で前面の文書が無いときは、検索のメニューが灰色になる（押されたら `No open document to search.`）。
  - 訂正:

## 8. 選んだ文書だけ（Find/Change Selected Documents (Book)）

- **SCOPE-26** ★フライアウトのトグル **`Find/Change Selected Documents (Book)`**（`Book Scope` のすぐ下）が ON で、**Book Scope も ON** のとき、
  対象のブック（SCOPE-04 のブック）を出している**ブックパネルで一部の文書を選んでいる**なら、その文書だけを相手にする
  （2026-10-07 の作者の依頼「選択されたドキュメントを検索置換（ブック）というトグルメニュー」）。
  - 訂正:

- **SCOPE-27** ★**何も選んでいない・全部選んでいる**ときは、ブックの全部の文書（今までと同じ・作者「選択０なら全てのドキュメント」）。
  InDesign 自身の「選択した文書」のコマンドと同じ決まり。
  ブックパネルが見つからない（アイコンに畳まれている・閉じている）・UI が無い（裏のスレッド・InDesign Server）ときも、ブックの全部。
  - 訂正:

- **SCOPE-28** トグルが OFF、または Book Scope が OFF なら、ブックパネルの選択は見ない（今までと同じ）。
  Book Scope が OFF の間、トグルは灰色で、チェックの印は見えたまま（SET-06 の Hide Previous Chapter と同じ）。
  - 訂正:

- **SCOPE-29** 選んだ文書に従うのは **Find・Change All in Book (No List)・保存したクエリの Run（第16章）の3つとも**。
  3つとも同じ1か所の判断に聞くので、食い違わない。メニューの名前・結果の文・ダイアログの `Runs on:` の行も、同じ判断から作る。
  - 訂正:

- **SCOPE-30** 選択は**その操作が走る瞬間**に読む。検索の後に選択を変えても、出ている行は変わらない。
  - 訂正:

- **SCOPE-31** 一部を選んでいる間は、**メニューの名前も変わる**＝`Find in Selected Documents`／`Change All in Selected Documents (No List)`。灰色の規則は名前が変わっても同じ。
  - 訂正:

- **SCOPE-32** 結果の文も選んだ文書の形になる（M＝一致のあった・書いた文書の数、S＝選んだ数、T＝ブックの文書の数）――
  検索＝`<N> hit(s) in <M> of <S> selected document(s) (<T> in the book).`（0件なら `No matches in the <S> selected document(s) of book "<ブック>".`）／
  Change All＝`<N> replaced in <M> of <S> selected document(s) (<T> in the book).`（0件なら `No match in the <S> selected document(s) - nothing was changed.`）／
  クエリの Run＝`Ran … replaced (…) in <S> selected document(s) of <T>.`／ダイアログの行＝`Runs on: <S> selected document(s) of the book "<ブック>".`（QRY-17）。
  - 訂正:

- **SCOPE-33** 選んだ文書が閉じていれば、今までと同じく窓を出さずに開き、検索なら返す・Change All なら書いた章に窓を付ける（SCOPE-10・SCOPE-20）。
  選ばなかった文書は開かない。
  - 訂正:

- **SCOPE-34** トグルは Save Panel Settings で保存する（キー `selectedDocuments`＝SET-16）。Book Scope は保存しないので（SET-17）、
  ON のまま保存して次に起動すると、Book Scope を ON にするまで灰色でチェックの印だけ見える。
  - 訂正:

## ⬜ この章で未確認

この章を書くにあたって**確かめていない**もの。「書いていない＝そういう決まりが無い」ではない。

- SCOPE-04 の「タブを選んでもアクティブにならない」は 2026-07-27 の実測で、InDesign 21 で測り直してはいない。
- SCOPE-05：ブックパネルが**浮いているが別のパネルの陰にある**ときに「前面のタブ」と読まれるかは、この章のためには測っていない。
- SCOPE-13：`subst` 以外の別名（ネットワークのパス・シンボリックリンク）で開いた章が同じと見なされるかは測っていない。
- SCOPE-18 ③（本体が閉じるのを断る）がどんなときに起きるかは、コードの守りとして書いてあるだけで、実際に起きた記録は見つけていない。
- SCOPE-20：置換の後の Ctrl+Z（取り消し）で保持中の章がどうなるかは、この章では確かめていない。→ 第9章
- SCOPE-21：Clear Results の予約の閉じ方で、閉じる前に（スクリプトから続けて）All Documents の検索をしたとき、2026-10-02 の取り違えが起きないかは測っていない
  （ふつう検索の後に保持中の章は残っていない＝閉じるか窓を付けて渡す・SCOPE-10）。
- SCOPE-26：選択を読むのは「対象のブックを出しているブックパネル」で、前面のタブかどうかは問わない作り。対象のブックはふつう前面のタブのブック（SCOPE-04）なので、前面でないパネルを読むのは、ブックパネルを別々のパレットに引き離したとき（BPP-07）くらい＝実機では測っていない。測ったのは、別のブックで選んでも対象のブックは全体になること（回帰 `sd-other-book`・テスト用ビルドの故障スイッチで選択を差し込んだもの）と、前面のパネルでの実クリック（`sd-real-click`）。
